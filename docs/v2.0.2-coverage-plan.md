## Evidence rules

A behavior is promoted only with a verifier-clean live capture, sanitized
transcript or exact vector carrying its full capture hash, and deterministic
public-API or production-decoder coverage. Exact entitlement, account,
market-state, and TWS-only failures remain blocked success paths even when the
typed failure itself is replayed.

Fault injection may chunk, truncate, corrupt, delay, or disconnect
live-derived frames. It may not invent a successful broker reply. Official
SDK output is a conformance oracle, never production code or a substitute for
live Gateway behavior.

## Safety boundaries

- `readonly-live` at `127.0.0.1:4001` is real-money and API-read-only.
- `paper-dev` at `127.0.0.1:4002` is the only endpoint allowed to place,
  replace, exercise, or cancel orders.
- The authorized regulatory snapshot is consumed and must never be retried.
- Do not issue another option-exercise instruction from the retained campaign.
- Manual `orderBound` evidence requires paper TWS and user participation; do
  not automate TWS or Gateway through GUI tooling.
- Do not mutate TWS/Gateway configuration.
- Every paper campaign must baseline and reconcile open orders, positions,
  executions, fees, and account values, flattening only its own delta.

## Version and SDK disposition

The exact negotiation replay covers all 18 supported versions and rejects 207
and 226. Native or official-SDK vectors freeze each implemented migration
boundary from 208 through 225; the detailed hashes live in
[`protocol-audit-sv208-225.md`](protocol-audit-sv208-225.md).

API 10.50.01 adds `ContractDetails.settlementMethod` at field 65 and
`Order.conditionsIncludeOvernight` at field 145 relative to 10.48.01. Field
65 is implemented and live-replayed at sv225. Field 145 requires server
version 226 and is intentionally outside the supported range.

```text
go mod tidy -diff
go mod verify
gofmt -l .
go build ./...
go vet ./...
CGO_ENABLED=0 GOOS=linux GOARCH=386 go build ./...
golangci-lint run
go test -shuffle=on -count=1 ./...
go test -race -shuffle=on -count=1 ./...
./scripts/check-api.sh
./scripts/check-api.sh --exact
./scripts/fuzz-all.sh --check
go run golang.org/x/vuln/cmd/govulncheck@v1.6.0 ./...
```

The default API check preserves compatibility with v2.0.2. Exact mode freezes
the reviewed `testdata/api/v2.0.2.api` release manifest, SHA-256
`39cd9b34e93e8d9043edd7764c931df8c3a398a41db5bf8dcbeb2fa5cdc9cefb`.
Old manifests are never updated to make a check pass.

The complete command block passed on 2026-08-28 on the exact candidate tree.

Release acceptance also requires transcript provenance, catalog invariants,
paper-state reconciliation, no repeated regulatory snapshot or exercise
instruction, and an explicit release note for every remaining external
decoder blocker. Tagging, pushing, and publishing remain separate user-owned
